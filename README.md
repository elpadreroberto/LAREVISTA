# LAREVISTA

Artículos de *Cristo Rey en México*, publicados para consulta libre.

https://elpadreroberto.github.io/LAREVISTA/

El sitio es un solo archivo, `index.html`. Los años que todavía no tienen
artículos aparecen atenuados en el menú. Están los de 1953 a 1974 y
marzo-abril de 2014. De 1966 solo está enero-febrero. 1973 no trae
enero-febrero. En 1974, septiembre a diciembre es un solo número.
Marzo-abril de 2014 es el OCR, sin la corrección de 1953–1966. Los
números de 1967 a 1974 salen de los Markdown ya cortados en artículos.
Noviembre-diciembre de 1972 es un número extraordinario, el 14–15.

Para añadir artículos más adelante:

1. Volver a generar `index.html` a partir de los Markdown nuevos.
2. Copiar ese archivo aquí, en lugar del anterior.
3. Subirlo a la rama `main`. GitHub Pages publica esa rama.

No hace falta cambiar el nombre del sitio ni la dirección.
